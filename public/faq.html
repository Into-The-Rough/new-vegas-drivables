Release & compatibility

When is it coming out?

Aiming for December.

Videos are on Oliver Swanick Productions. You can also find me on Nexus.

Does it need The Frontier?

No. It has nothing to do with The Frontier and does not need it installed.

Please don’t use these pages to dunk on it. Criticise my mod if you like, but leave other modders out of it.

Does it support Tale of Two Wastelands?

Yes, TTW is supported.

What about Viva New Vegas?

New Vegas Drivables has been developed and tested with Viva New Vegas in mind.

Can I install it during a playthrough?

Yes. It is safe to install mid-playthrough. You do not need to start a new game.

Will there be a Fallout 3 or Fallout 4 version?

No. This is a New Vegas mod. TTW support does not mean a separate Fallout 3 release.

Playing

Can I use a controller or Steam Deck?

Yes. Controllers are supported, and the mod has been tested on Steam Deck.

Click both sticks together to open the F10 menu. The visual control guide has Xbox and Steam Deck button labels, with separate layouts for different rides.

What about first person?

First person has improved, but it will never be my priority.

Where do I find a vehicle?

Start with the placement map. It shows where vehicles are, what condition they start in and what you need to claim them. You can hide exact locations if you would rather explore.

Some work straight away. Others need repairs, a quest completion or a race win. The first ride guide walks you through it.

Can companions ride too?

Yes. Suitable vehicles have passenger positions, and eligible humanoid companions can ride horses alongside you. The companion guide lists the seats and explains the restrictions.

Do I have to keep buying fuel and parts?

Powered vehicles use the supply listed in their entry. Jerry Cans, cells and Reactor Coolant cover the different types. The Alien Recon Craft and human-powered rides need no fuel.

Required repair tools and components are consumed when used. See fuel and repairs for the details.

My vehicle is stuck. What now?

Use Recover in the F10 garage. On supported rides you can also hold View / Back for 0.7 seconds. A short tap changes camera instead.

Make it your own

Press F10, or click both controller sticks together. These options are under Settings → Loading. Apply your changes before leaving the menu.

“I don’t like the loading wheels.”

Set Loading wheel to Off. The change takes effect when a fresh loading screen opens. It leaves whichever loading spinner you otherwise have installed.

“I don’t like the main menu replacer.”

Set Main menu background to Off, apply it, then restart the game. It takes effect from the next launch.

“I don’t want vehicle loading screens either.”

Set Loading screens to Off. This removes the mod’s studio shots and driving tips from the rotation, leaving the game’s and other mods’ screens.

Prefer to change the configuration file?

With the game closed, edit Data\config\DrivablesNVSE_settings.ini in your active mod setup. These are saved overrides. Add or update the relevant entries under the existing [Display] section, or create that section if it is missing.

[Display]
bLoadingWheel=0
bMainMenuBackground=0
bLoadingScreens=0

Use only the lines for the features you want to turn off. Set a value to 1 to enable it again. If you use Mod Organizer, the saved settings file may be in Overwrite.

“The camera moves too much.”

F10 has Full, Reduced and Off camera motion options, plus settings for speed FOV, road shake, camera tilt and jump slow motion. Start by reducing camera motion.

“I don’t want stunt XP.”

Set Stunt XP to Off under F10 → Settings → Showtime.
