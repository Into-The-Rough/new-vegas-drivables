The mod

New Vegas Drivables is a Fallout: New Vegas mod by intotherough.

The guide

Locations, restoration requirements and unlock routes come from the mod’s placement records and implementation notes. Vehicle images are renders of the mod’s assets. The amber text, selection outlines and tabs follow the in-game F10 menu.

Map & game

The Mojave map artwork and Fallout: New Vegas belong to their respective rights holders. This is an unofficial fan project.

Font

Monofonto by Ray Larabie, the typeface used for the game’s menu text. This site includes the unmodified 2.000 (2004) release and its original readme and licence, which permits use and redistribution. The original package is available from Abstract Fonts; the designer’s current catalogue is at Typodermic Fonts.
